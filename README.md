# Математика для Вани — тренажёр для iPhone и Android

PWA-приложение (веб-приложение, которое ставится на главный экран телефона как
обычное приложение): таблица умножения и степени, два режима тренировки
(«Скорость» и «Пробелы»), статистика по дням, стрик 🔥, XP и уровни, ачивки,
карта освоенности, встроенные правила игры. Всё на русском, работает офлайн,
данные хранятся на телефоне.

## Как поставить на iPhone

1. Открой в Safari: **https://pancratyus.github.io/math-for-vanya/**
2. Поделиться (квадрат со стрелкой) → «На экран “Домой”» → «Добавить».
3. Готово: иконка на главном экране, запускается как приложение, работает офлайн.

## Как поставить на Android

Работает так же (Android поддерживает PWA даже лучше iPhone):

1. Открой в Chrome: **https://pancratyus.github.io/math-for-vanya/**
2. Меню ⋮ → «Добавить на главный экран» (Chrome также может сам предложить
   «Установить приложение» баннером внизу).
3. Готово: иконка, полный экран без адресной строки, офлайн — всё как на iPhone.

> Нюанс: прогресс (XP, стрик, статистика) хранится **на каждом устройстве
> отдельно**. Если тренироваться с iPhone и с Android — статистика не
> синхронизируется, у каждого телефона своя.

## Резервный способ — по Wi-Fi с этого Mac

1. На Mac запусти сервер (в терминале, из этой папки):
   ```bash
   python3 -m http.server 8123 -d app
   ```
2. Узнай IP Mac в Wi-Fi-сети:
   ```bash
   ipconfig getifaddr en0
   ```
3. На iPhone (тот же Wi-Fi) открой в Safari `http://<IP-Mac>:8123`
   (например `http://192.168.1.5:8123`).
4. Поделиться → «На экран “Домой”» → «Добавить».

Работает, пока включён Mac и тот же Wi-Fi. Основной способ — ссылка выше.

С HTTPS заработает полный офлайн (service worker): закачка обновится один раз,
дальше работает без интернета.

## Как обновить приложение

1. Правишь файлы в `app/`.
2. **Чек-лист обновления (обязательно):**
   - **Правила игры в приложении актуальны?** Экран «📖 Правила игры»
     (`rulesHtml` в `app/js/ui.js`) должен точно описывать текущую механику:
     пороги, XP, режимы, бонусы. Изменил игру — обнови правила.
   - Изменения в формулах/правилах — отрази в `PROJECT_STATE.md` §4.
   - Прогони тесты: `node tests/engine.test.mjs`.
3. **Подними номер версии** в `app/sw.js`: `const VERSION = 'math-vanya-v3'` → `'math-vanya-v4'`
   (иначе телефоны продолжат работать со старым офлайн-кэшем).
4. `git push` — GitHub Pages задеплоит автоматически (workflow `deploy-pages.yml`).
   На телефоне открыть приложение дважды (первый запуск подтянет новый SW,
   второй — покажет новое).

## Структура

```
app/                    — всё приложение (эта папка = весь сайт)
  index.html            — единственная страница
  manifest.webmanifest  — манифест PWA (иконка, имя, полноэкранный режим)
  sw.js                 — офлайн-кэш (версия — VERSION)
  css/styles.css
  js/engine.js          — чистая логика: пулы, режимы, освоенность, XP, ачивки
  js/storage.js         — сохранение прогресса (localStorage, ключ mv_state_v1)
  js/audio.js           — звуки (WebAudio, без файлов)
  js/ui.js              — экраны (HTML-шаблоны)
  js/main.js            — навигация, сессия, события
  icons/                — иконки
scripts/make_icons.py   — генератор иконок (python3 + Pillow)
tests/engine.test.mjs   — тесты логики: node tests/engine.test.mjs
PROJECT_STATE.md        — решения и состояние проекта (для продолжения работы)
```

## Правила игры (кратко)

- **Скорость** — весь набор примеров вперемешку (таблица 2–10: 45 примеров,
  `3×4` и `4×3` — одно; умножение на 10 выпадает в ~2,4 раза реже остальных;
  степень два 1–20 по умолчанию — диапазон настраивается вплоть до 100;
  степень три 1–12; степень четыре 1–5). Подпись кнопки показывает, сколько
  вопросов будет в выбранной длине сессии.
- **Пробелы** — только проблемные: 2 ошибки из последних 3 ответов или верные
  ответы дольше порога (по умолчанию 4 с, меняется в настройках). Нужно ≥5
  проблемных, чтобы режим включился.
- Ошибка → показывается правильный ответ («Правильно: N») и что был набран,
  пример возвращается в конец очереди этой же сессии (макс. 2 повтора).
- Сессия: 20 вопросов или весь набор — на выбор перед стартом.
- **Учитывается только сессия, доведённая до конца**: ответы копятся в
  «черновик» и записываются при финише. Ранний выход ничего не записывает —
  «ознакомительные» заходы статистику не портят.
- XP: верный 10 (быстрый — 15), неверный 1; бонус за сессию до +75.
- Стрик растёт за каждую доведённую до конца сессию в день.
- Плашка на главном экране (уровень/XP/стрик) нажимается и раскрывает
  объяснение: за что даётся XP, лестницу званий и общую статистику.
- Внизу главного экрана — таблица Пифагора как шпаргалка (клетка = строка × столбец).
- Все диалоги (выход из сессии, сброс прогресса) — внутренние окна приложения:
  нативные `confirm()`/`alert()` в установленном PWA на iOS ненадёжны.
