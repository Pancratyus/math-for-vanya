# СОСТОЯНИЕ ПРОЕКТА — «Математика для Вани»

> Последнее обновление: 2026-11-12

## 1. Что это за проект

PWA-приложение (веб-приложение, устанавливаемое на главный экран iPhone) —
тренажёр математики для школьника (Вани). Два раздела тренировки — таблица
умножения и степени, два режима тренировки («Скорость» и «Пробелы»),
статистика по дням и геймификация.

## 2. Принятые решения (подтверждены пользователем 2026-11-12)

| Вопрос | Решение |
|---|---|
| Технология | **PWA** — vanilla JS/CSS, без сборки; ставится на экран «Домой» iPhone через Safari |
| Таблица умножения | От 2 до 10; `3×4` и `4×3` — **один** пример → **45 уникальных** |
| Степени, уровень 1 | Квадраты чисел **1–100** (100 примеров) |
| Степени, уровень 2 | Кубы чисел **1–12** (12 примеров) |
| Степени, уровень 3 | 4-я степень чисел **1–5** (5 примеров) |
| Режимы тренировки | **«Скорость»** — весь пул в случайном порядке; **«Пробелы»** — только проблемные примеры. Доступны для обоих разделов |
| Длина сессии | На выбор перед стартом: **20 вопросов** или **весь набор** |
| Случайный порядок | Перемешивание всего пула без повторов, пока пул не пройден (нельзя «20 раз 2×2 и ни разу 3×3») |
| Неверный ответ | Правильный ответ показывается зелёным 1,5 сек, пример возвращается в конец очереди текущей сессии (макс. 2 повтора на пример за сессию); в статистике — ошибка |
| Таймер | Секундомер на каждом вопросе (виден), время пишется в статистику |
| Алгоритм «Пробелов» | Умный: проблемный = ≥2 ошибки из последних 3 ответов **или** верный ответ дольше порога (по умолчанию **4 сек**, настраивается в настройках 2–12 сек). Пример сам выходит из «Пробелов», когда становится стабильным (последние ответы верные и быстрые) |
| Кнопка «Пробелы» | Недоступна, пока проблемных примеров < 5, с подсказкой |
| Геймификация | **Всё выбрано**: стрик по дням 🔥, XP и уровни со званиями, ачивки-медали, карта освоенности (клетки красный→зелёный) |
| Экран статистики | По дням (последние 7 дней, точность + кол-во), сравнение с прошлой неделей, карта освоенности по разделам, список проблемных, ачивки |
| Настройки | Порог «медленного» ответа (слайдер), звук вкл/выкл, сброс прогресса |
| Язык интерфейса | Русский |
| Данные | localStorage телефона (один JSON-ключ `mv_state_v1`), офлайн через service worker |

## 4. Формулы и правила (чтобы любой агент продолжил консистентно)

- **Идентификатор примера**: `mul:a:b` (a≤b, 2..10), `pow2:n`, `pow3:n`, `pow4:n`.
- **Запись ответа** по элементу (в `items`): история последних 10 ответов
  `h: [{o:0|1, t:сек}]`, всего `a` попыток, `c` верных.
- **Освоенность** mastery ∈ 0..1: по последним 5 ответам, вес свежее = больше
  (w = 0.6^i), балл ответа: ошибка → 0, верный → clamp(порог/время, 0.2, 1).
- **Проблемный** (динамически, не хранится): ошибок ≥ 2 в последних 3
  ИЛИ последние ≥1 верный и среднее время последних 3 > порога.
- **XP**: верный = 10 (+5 если быстро, t ≤ порога), неверный = 1;
  бонус за сессию: точность ≥ 90% → +30, 100% при ≥10 вопросах → +75.
- **Уровень**: до следующего нужно `100 + (L-1)*60` XP.
  Звания: 1-2 Новичок, 3-4 Ученик, 5-6 Знаток, 7-8 Умник, 9-11 Магистр, 12+ Профессор.
- **Стрик**: обновляется при завершённой сессии (сегодня → без изменений,
  вчера → +1, иначе сброс на 1).
- **Ачивки** (16): first_session, answers_100, answers_500, perfect_10,
  streak_3, streak_7, streak_30, mul_half (23/45), mul_all, sq_all, cubes_all,
  pow4_all, fast_15 (15 верных подряд быстрее порога за сессию), level_5,
  level_10, speed_full (полная сессия «Скорость» по таблице с точностью ≥90%).
- **Дни**: ключ `YYYY-MM-DD` локальной даты: {s: сессий, a: ответов, c: верных, xp}.
- Клавиатура: 3×4 (1-9, ⌫, 0, ✓), крупная; ответ ≤ 6 цифр.
- Выход из сессии до конца: ответы по примерам и XP за ответы сохраняются,
  но сессионные бонусы и стрик — нет.
- **Экран «Правила игры»** (`rulesHtml` в ui.js, кнопка на главном экране):
  внутриигровая справка для пользователя. **Правило сопровождения:** при любом
  обновлении механик сверять этот экран с фактическим поведением и обновлять
  его — пункт чек-листа обновления в README.md.

Важные исправления по итогам проверки:
- навигация степеней: главный → «Степени» (уровни) → режимы (был тупик);
- плюрализация «1 день / 2 дня / 5 дней» на экране итогов;
- компактные подписи клеток карты (2×10 в одну строку);
- обновление кэша SW: при изменении файлов поднимать VERSION в sw.js
  (уже v2; гонка «первая перезагрузка после очистки кэша обслуживается
  старым SW» — нормальное поведение, на проде решается bump-ом версии).

Как проверить самому:
```bash
cd "1. математика для Вани"
python3 -m http.server 8123 -d app
# на iPhone в Safari (тот же Wi-Fi): http://<IP-Mac>:8123
# IP Mac: ipconfig getifaddr en0
```
Затем в Safari: Поделиться → «На экран Домой». Подробности — в README.md
(включая бесплатный HTTPS-хостинг для полного офлайна).

Если нужно продолжить доработку — читай разделы 2 и 4 (решения и правила),
смотри README.md.
